# 教训

- **2026-11-15 入库的文件里不能有本机用户名。** 用户要求仓库能公开，连 `/Users/<用户名>/` 这种路径都不能出现。写文档、提示词、脚本时用仓库内相对路径或 `~/`；给子代理的说明也一样（它会原样写进产物）。提交前 `git grep -i <用户名>`。
- **试验目录提交前先看清要加进去的是什么。** 1.4 时 `git add -A` 把 Remotion 下载的 193MB 浏览器（`.remotion/`）、技能作者的演示截图（他人短信）、macOS 壁纸、无许可证仓库的原样代码都提交了，公开前只能改写历史。新试验先把工具缓存目录加进 `.gitignore`，第三方素材和代码默认不入库，只留自己的记录和拼图。
