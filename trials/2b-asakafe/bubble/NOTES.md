# 气泡版 ep001：说明

成片：`out/ep001_bubble.mp4`（1080×1920，30fps，29.91 秒，带音轨）。拼图：`contact.png`（每 0.5 秒一帧）。设计稿：`PLAN.md`。

## 做了什么

整片是**一条不断的居酒屋聊天**：部长的话、主持人的提问、你的回复都是同一条对话流里的消息，从底部一条条长出来，旧的往上移，全片不清屏、不淡到全空。版式从头到尾固定成五块：

| 区 | 内容 |
|---|---|
| 门帘头 | 藍色暖帘（底边开衩、下摆轻摆）+ 摆动的红灯笼，标题「欢迎会 · 邻座的部长」 |
| 步骤条 | ① 被夸 ② 怎么回 ③ 你来答，黑色高亮块滑过去（有过冲和回稳） |
| 对话流 | 占屏幕中间约 1100px，顶部渐隐 |
| 提示行 | 一句旁白或要点，换句时交叉淡入 |
| 输入框 | 「你」这边的事都在这里：犹豫着打字、听两遍、跟读、倒计时、发送 |

## 每段怎么演

- **① 被问**：0 帧就有一张「今晚 19:30 新人欢迎会」活动卡（灯笼、吧台、两杯啤酒在碰，矢量画），交代场景。部长的气泡原地弹出，日文**按音频逐字浮现**（带注音），说完中文释义再淡入。头像外圈跟着音量鼓起，头像旁的迷你声波条是这句的真实音量包络，播放头扫过的格子变色。
- **留白**：你这边冒出「正在输入…」，输入框里一个字一个字打出「いいえ、」，停顿，再打「下手です」；点点只在打字时跳，停手时停，表现犹豫。配了很轻的按键声。
- **② 主持人**：用深色居中卡片（麦克风标），和对话气泡一眼区分，中文逐字随音频浮现，环境声压低。
- **留白 1 秒**：刚才打的草稿「发了出去」，变成虚线幽灵气泡，红线划掉，弹出 ✕ 章（配划笔声）；提示行出现「**别否认。**你一否认，对方还得再夸一轮。」
- **两遍目标句**：朱红色的回复气泡，标着「✓ 这样回」和 ●○ 遍数；每遍**卡拉 OK 式扫亮**（字内平滑横扫，当前字微微上抬），两遍之间亮色回落。输入框显示「听两遍」和播放进度。
- **跟读留白**：输入框变成「轮到你说 · 跟着读一遍」，麦克风键变红、呼吸，外圈进度 2.5 秒走完。
- **③ 再来一遍**：分隔条「③ 再来一遍 · 这次你来回」；分隔条以上的旧消息**蒙上磨砂**（不然上面那句答案还看得见）。部长的重放气泡**不给字**，里面是 `visualizeAudio` 的实时频谱声波 +「只听，不看字」。
- **倒计时**：你这边「正在输入…」，输入框的麦克风键里 3-2-1 弹出，外圈每秒走一圈，配 tick。
- **参考答案**：发送键一按，答案气泡弹出并卡拉 OK 扫亮；部长那条被遮住的气泡随后揭开文字（让你核对刚才听到的）；磨砂散去。
- **部长反应**：反应气泡逐字浮现，同时你的答案旁弹出「🍺 乾杯！」回应章（配碰杯声）；提示行「不否认，话题就自然接下去了」；结尾部长又在「正在输入…」，对话还在继续。

## 用上的做法

1. **先有声音再做画面**：所有时刻从 `segments` 推出（改 gaps 画面跟着走）。字和音频的对齐是自动算的：读入波形 → 找有声片段 → 按标点切出的短语用 DP 对到连续的有声片段上 → 短语内按假名数（汉字按注音字数）分配时间。实测和音频的停顿对得上（例：ask 的「リンさん、｜日本語、｜お上手ですね。」落在 0–0.78 / 1.06–1.68 / 1.74–2.70 秒）。
2. **帧驱动、确定性**：只用 `useCurrentFrame()`；没有 random、Date、CSS transition/animation；`interpolate` 两端 clamp；没用 spring，过冲都写成显式关键帧。
3. **disney 阶段表**：消息入场 = 堆叠先下沉 4%（预备）→ 推上去到 105% → 98.5% → 回稳；气泡从尾巴角 0.5→1.06→0.98→1；头像行晚 3 帧到（次要动作）；章、倒计时数字 0.4→1.14→0.96→1。保持段也有活气：灯笼和门帘摆、光标闪、跟读时麦克风呼吸、说话人头像外圈跟音量。
4. **字号不写死**：字号、行高、气泡留白、网格都集中在 `src/film/layout.ts`；日文全角字宽就等于字号，所以折行和气泡高度能精确算出来，堆叠不用量 DOM。
5. **音效**：复用环境声、pop、tick、碰杯；新加两个 Freesound CC0（按键 fs:640365、划笔 fs:211247，出处已记在 `src/assets/sfx/CREDITS.md`），音量都压在人声下面。成片 max −1.5 dB。

## 自查改了什么（三轮「看 → 改」）

1. 「你」那边的头像行折成好几行（「我（リン）」竖排、标签断行）：消息容器原来只有气泡宽，改成占满对话流宽度，标签不折行。
2. 部长重放气泡里的频谱几乎是平线：加大增益；没在播的时候改成画这句录音的淡色静态包络，不再是一条虚线。
3. 回应章的啤酒杯太小、泡沫在浅底上看不见：重画杯子（泡沫带描边），章里加「乾杯！」；第二轮发现它盖住了「参考答案」标签，第三轮又盖住了中文释义，最后挪到气泡左侧外面。
4. 开场上半屏大片空白：活动卡加高、加灯笼排和吧台；第一条部长气泡的位置一开始就留好、原地弹出，0 帧画面不空。
5. 灯笼光晕被 SVG 裁成灰色方块：改成单独的径向渐变。
6. 幽灵气泡的「✕ 别这样回」单独占一行头像行，把主持人卡片挤出屏幕：改成跨在气泡上沿的小牌，省了 74px。
7. 倒计时时提示行和输入框写的是同一句：提示行改成「用刚学的那句，回部长」。
8. 输入框、提示行换状态时新旧文字叠在一起：改成旧的先走完（5 帧），新的再进来。
9. 去掉了拷贝过来但用不到的人物/位图/场景文件（Puppet、Sprite、Stage、Scene 等）。

## 还剩的问题

- 部长的气泡一出现就是最终大小，字随声音往里流，所以句子说到一半时气泡下半截是空的（直播字幕的样子）。想要气泡跟着字长高，可以做，但会让整条流在说话时持续往上蹭。
- 幽灵气泡从输入框「发出去」只是输入框清空、对话流里弹出，没有做一条从输入框飞到对话流的路径。
- ③ 开始时分隔条和部长重放气泡相隔 0.3 秒入场，两次上推挨得比较紧。
- 文字对齐靠静音检测，换一集如果句子里没有明显停顿，会退化成按假名数平均分（仍然在有声时间内，不会离谱）。
- 主持人卡片在两遍目标句期间被推到对话流顶部的渐隐区，标题行有点淡。
