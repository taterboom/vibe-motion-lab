### ① wait（2.88–4.88）
- 你：脸红从 0 升到 1（3.1–3.5），右手抬到脸边（3.3–3.65，害羞），眼神乱飘：看部长 3.0 → 低头 3.7 → 回看 4.2 → 偏下 4.55；嘴变成波浪形（不知道怎么接）；3.75 起头顶「…」气泡。
- 部长：笑眯眯**前倾等待** 4°→9°（3.0–3.6），头歪 5°，3.9 一次鼓励的小点头，眉毛微抬。
- 提示行 3.2 出现：「如果是你，怎么回？」

### ② host / hostPause（4.88–9.18）
- 镜头拉到头像条；**教学卡片** 5.05 起从画框底部升起（3 帧下沉预备 → 上升 → 过冲 → 回稳，0.5s）。
- 卡片第 1 行：✕「いいえ、下手（へた）です。」5.55 淡入，6.95–7.25 红线划掉（对上主持人说「不尴尬」），7.25 出灰字「生硬否认 → 对方只好再夸一轮」。
- 卡片第 2 行（8.25 / 8.40 依次滑入）：○ 两块拆解：「え、本当ですか？」= 先惊讶一下；「うれしいです。」= 再收下夸奖。
- 你：头像条里歪头、手托下巴想、旁边「？」；8.5 想通了，眉毛一扬、笑。
- 部长：笑着等，偶尔小点头。
- 字幕槽：说话人签「主持人」，中文问题按音频分两块扫亮；8.85–9.15 换成目标句（还没高亮）。

### ② play1 / gap / play2（9.18–15.12）
- 你在头像条里**口型跟读示范音频**，并做和参考答案同一套表演（见 ③ answer）；部长在「うれしい」时开心点头。
- 字幕槽：目标句卡拉 OK 高亮（强调色从左向右扫，扫到的字注音也一起变色）；卡片上对应的拆解块同时亮起。
- gap：高亮 0.25s 退回，签换成「第 2 遍」。提示行：hook「别否认。你一否认，对方还得再夸一轮。」

### ② shadow（15.12–17.62）
- 你转向镜头（正面）笑着、右手伸出示意「轮到你」，不张嘴；部长也转向镜头，歪头听。
- 字幕槽：目标句以另一种颜色（青绿）**无声按原速扫一遍**当节拍；提示行「▶ 轮到你：跟着高亮说出来」+ 下方细进度条。
- 卡片右上角麦克风图标，按进度呼吸。

### ③ ask2（17.62–20.50）
- 卡片退出（向上 3 帧预备 → 加速落下）；镜头推到部长中景。
- 部长：从面向镜头**再次转身**朝你（预备 → 转 → 过冲），和 ① 同样的点头节拍，但杯子举得更高一点（第二遍略不同，不是复制）。
- 你：转回部长，听；不出 take（这次有准备了），只在 2.6 眉毛一抬。
- 字幕槽：**不显示台词**；耳朵图标 +「这次不看字幕，用耳朵听」+ 五根随部长音量跳的音量条。

### ③ countdown（20.50–23.50）

- 你：困扰脸，眼神每 0.5s 左右乱瞟（2 帧的快速眼跳），21.0 / 22.0 各冒一滴汗沿脸滑下，22.9 咽口水（头一沉）。
