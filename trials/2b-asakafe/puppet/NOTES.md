# ep001 角色版 · 做了什么

成片：`out/ep001_puppet.mp4`（1080×1920，30fps，29.9 秒，带人声 + 环境声 + 音效）
抽帧拼图：`contact.png`（每 0.5 秒一帧，10×6）
分镜 / 阶段表：`PLAN.md`

## 画面设计思路

- **画框变大**：场景画框从上 1/3 放大到 1024×1090，占画面 57%；下面是固定的文字区。
- **版式全片不变**：顶栏（栏目名 + ①②③ 三段进度条，当前段高亮）→ 画框 → 说话人签 → 主字幕（日文两行 + 注音）→ 中文 → 提示行 → 片名。每个槽位的位置从头到尾都一样，只换里面的内容；内容变了先淡出旧的（0.1s）再进新的（0.18s），不叠字。
- **字幕在画框外**：镜头会推到脸部特写，叠在画面上一定会挡脸，所以字锚在框外。
- **卡拉 OK 高亮**：所有日文台词都按音频进度逐字扫亮（分块时间点来自 silencedetect + RMS 包络），注音跟它的汉字一起变色。颜色区分段落：部长 = 红，示范 = 红，跟读 = 青绿，参考答案 = 绿。
- **镜头**：写成关键帧轨道（缓入缓出 + 3% 左右的过冲），开场双人全景 → 推到部长 → 夸完甩到「你」赶上 take → 段 ② 拉到「头像条」机位 → 段 ③ 推回部长 → 倒计时甩到「你」的脸并每秒向前 punch-in 一次（1.45→1.60→1.76）→ 回答时拉回 → 碰杯那一帧有 4 帧的轻微冲击 → 片尾拉回全景。叠了 ±2px 的手持漂移，教学段降到 40%。

## 每段怎么演

- **① 被问**：部长先**反向转一点（预备）再转向你**、转过头再回稳，杯子同步抬起；「日本語 / お上手 / です / ね」四个重音各点一次头，「お上手」时眉毛上扬。「你」先低头看菜，听到「リンさん」时**眼睛先转、头后转**，头发滞后。夸完立刻一个 **take**：下沉眯眼（0.17s）→ 拉伸睁大眼 + 「！」（0.13s）→ 阻尼回稳，头发晚 0.1 秒落下。
- **① 等你答**：你脸红、手捂脸、眼神乱飘、嘴变波浪、冒汗、头顶「…」；部长**笑着前倾到 9°、歪头**，鼓励地点一次头。提示行：「如果是你，怎么回？」
- **② 主角**：教学卡片从画框底部升起（过冲回稳），两人的头留在上面继续演（你托腮想 + 「？」，部长笑着等）。卡片：✕「いいえ、下手です。」在主持人说「不尴尬」时被红线划掉 + 「生硬否认 → 对方只好再夸你一轮」；○ 把目标句拆成两块「① 先惊讶一下 / ② 再收下夸奖」。两遍示范时你在头像条里**对口型说这句**，字幕和卡片两块同时卡拉 OK 高亮；镜头慢慢靠向你。两遍之间高亮淡出。**跟读**时两个人都转向观众，你伸手示意「轮到你」，字幕用青绿色**无声按原速再扫一遍当节拍**，提示行 +进度条，卡片右上角麦克风。
- **③ 再来一遍**：卡片退场，部长再次转身说同一句（杯子举得更高，不是复制）。**不出台词**：字幕区换成耳朵图标 + 跟部长音量跳的音量条 +「这次没有字幕，用耳朵听」。
- **③ 倒计时**：镜头逐秒逼近你的脸；你冒两滴汗、眼神每 0.4s 乱瞟（2 帧的眼跳）、手攥在胸前微抖、最后咽口水；字幕区大数字弹入 + 外圈按秒走完；tick 对每个数字。
- **③ 参考答案**：镜头拉回；你「え」小 take（拉伸、睁大眼），「本当ですか？」歪头前探、手按胸口、「か？」再挑眉，「うれしいです」变 ^^ 眼、脸红、**小鞠躬 + 点头**、头顶星星。部长「え」时挑眉、「うれしい」时笑眯眼往后一靠。
- **③ 部长反应**：先吸气（笑的预备）；「いやいや」**胸前摆手三下**、笑得身子一颤一颤、轻摇头；「本当に」点头、杯子**先下沉再沿弧线冲上去**，你同时举杯，两只杯口在台词停顿处（27.82s）**精确相接**（由世界坐标反解两只手的位置），clink 音效的击打点对齐到这一帧，杯子各弹回 7px、泡沫滞后晃、溅出三滴；「日本はどれくらい？」部长前倾歪头挑眉（话题往下走），你眼睛往上看、托下巴在想。提示行：「✓ 收下夸奖，话题就接下去了」。

## 用到的做法

1. **先有声音再做画面**：所有动作锚在「段起点 + 句内偏移」，句内节拍从音频测出来（写在 `src/script.ts`）；嘴的开合跟音量（2 帧一换）。
2. **帧驱动、确定性**：整片表演是一个纯函数 `showAt(t)`（`src/perform.ts`），没有 random / Date / CSS 动画；次要动作（头发、泡沫、杯身倾角）用**延迟采样主动作**算出来，不做逐帧累积。
3. **disney 阶段表**：每个动作先写阶段（预备 → 动作 → 过冲 → 回稳），再挑缓动；碰杯用「末端保留速度」的缓入才有「碰」的力度；保持段始终有呼吸（躯干 ±1.2%）、确定性眨眼（转头时补眨）。
4. **自己看画面**：半尺寸渲整片（约 10 秒）再用 ffmpeg 抽关键帧拼图看，比逐帧 `remotion still` 快很多（并行跑 10 个 still 会卡死）。

## 自查发现并修掉的（三轮）

- 第 1 轮：镜头太近（中景 z1.32、特写 z2.2 脸撑满画框、「！」被切）→ 全部降一档；两只啤酒杯在画面中间挤在一起、两人手臂交叉 → 杯子放回桌面高度并拉开；手臂和衣服同色，手按胸口时像一颗纽扣 → 袖子加深 10%；IK 肘部往外撑压住对方的杯子 → 改成肘尽量朝下；开头第 0 帧进度条和字幕没出来 → 第一段直接出现；卡片下半截空 → 卡片变矮、头像条机位放大。
- 第 2 轮：「…」「？」气泡出框 → 挪进来；跟读时伸手示意在画框外 → 收回到肩前；「いやいや」摆手在画框外 → 改成胸前摆手；换段时新旧字幕叠在一起一帧 → 改成先出后进；部长的杯子在白衬衫前几乎看不见 → 杯身加细描边；② 有 12 秒机位不动 → 示范时慢慢靠向说话的你。
- 第 3 轮：成片里 clink 的击打点比预期晚 60ms（mp3 解码延迟）→ 提前量从 0.03s 改为 0.09s，实测击打点 27.83s 对上接触帧；腮红画到了头发上 → 腮红按脸形裁切。
- 音量：人声峰值 -1.5 dB，碰杯约为人声的 1/3，倒计时 tick -16 dB，环境声在段 ② 压低。

## 还剩的问题

- 人物是纯 2D 纸偶，「转身」只是五官横移，侧脸幅度有限；鞠躬是整体旋转，没有腰部关节。
- 段 ② 的卡片盖住了人物的手，你在想问题时托腮的手看不到。
- 「本当に」时部长的点头和举杯在 0.5 秒里一起发生，动作略密；如果要更从容，可以把碰杯挪到片尾（但那会压到「日本はどれくらい？」后面只剩 0.6 秒）。
- 没有做真正的音素口型，只按音量开合三档。
- 没有用新音效（卡片升起借用了低音量的 pop）。
