# STYLE_NOTES — 全片视觉基调（由 scene-001 确立）

规格：1080×1440，30fps，静音。项目源码在 `project/index.html`（hyperframes + 本地 GSAP 3.15，字体本地化在 `project/assets/fonts/`）。

## 调色板
| 角色 | 色值 | 用法 |
|---|---|---|
| 底色 ground | `#0c0d11` | 全屏背景，中上部 `#171a22` 径向微光 |
| 网格 | `rgba(255,255,255,0.035)` 60px | 背景细网格，制作台/取景器感 |
| 面板 panel | `#15171d` / `#111318` | 画面屏幕、终端卡片 |
| 线条 line | `#262932` | 时间轴、分隔 |
| 次要文字 muted | `#9a9fab` | HUD、英文小标签（对比度够 4.5:1） |
| 主文字 ink | `#f2efe8` | 暖白，标题、角标框 |
| **Lime** | `#c8ff4d` | 代码 / AI / vibe coding 的颜色；进度、高亮、发光 |
| **Orange** | `#ff6b35` | 人 / 创作者“我”的颜色 |

语义约定：橙 = 人，Lime = AI/代码。scene-002「AI 集团全自动」建议让 Lime 占主导、橙色退场或缩小；scene-003「Codex 指挥」可用 Lime 节点网络。

## 字体
- 中文：Noto Sans SC（600 / 800）。**当前 woff2 是按字子集**，新镜头若出现新汉字需重新从 Google Fonts 用 `text=` 参数取子集，或换全量字体。
- 拉丁/数字/HUD：JetBrains Mono（500 / 700），字距 0.06em，大写小标签。
- 文字最小 22–24px；关键词 34px 以上；主视觉字可到 168px 粗体。

## 固定版式元素（跨镜头复用以保持一致）
- 顶部 HUD：左 `● REC · SCENE 0N`（橙色圆点闪烁），右 `00:SS:FF` 时间码；y≈60，左右边距 72px。
- HUD 下方时间轴：936px 细线 + 7 个刻度 + lime 进度填充 + 菱形播放头；本镜头结尾停在最右端并亮起 `NOW` 绿色标签——scene-002「但此时此刻」可直接从 `NOW` 接续。
- 中部取景器：白色圆角 L 形四角框（6px 线）+ 内部深色圆角屏幕 + 左上 pill 标签（眼睛图标）。
- 底部页脚：左 `MANUAL · 人工 + VIBE CODING`，右 `01 / 03`。后续镜头改为如 `AUTO · AI 集团` / `02 / 03`。
- 卡片：圆角 24px；“人”卡为橙色实底黑字；“AI/代码”卡为深底 + 2px lime 描边 + 终端三点头部。

## 动效语言
- 缓动：入场 `power3.out`；弹出 `back.out(1.5–2.4)`；位移转场 `power3.inOut`；时间轴 `power2.inOut`。
- 节奏：元素 0.3–0.55s，stagger 0.04–0.08s，节拍跟字幕切点对齐。
- 构建感：画面元素逐层“搭起来”（scaleX/scaleY 从 0、圆形 back.out、LAYERS 计数器）。
- 打字：逐字 `tl.set` 显示 + 光标按字宽 28px 跳格，结束后光标闪烁（有限次 repeat）。
- 连接线：scaleY 从下往上生长，连接“制作者 → 画面”；完成时屏幕 lime 描边发光 + 盖章标签 `✓ 我 + vibe coding`。
- 收尾：最后约 0.5s 保持稳定，只做极轻微推近（scale 1.015）与环境运动，方便剪辑衔接。
- 确定性：只用 timeline 驱动，无 Date/随机数/网络；计数器用 onUpdate 读 tween 值。

## 本镜头结构（3.9s）
1. 0–0.83「到目前为止」：播放头扫过时间轴到 NOW，取景器四角向内合拢。
2. 0.83–2.0「你所看到的画面内容」：屏幕出现，示意画面元素逐层搭建（标题条、柱状图、橙色圆+播放键、lime 波浪线）。
3. 2.0–3.9「是由我加 vibe coding 做的」：取景器上移，底部「我」橙卡 + 「vibe coding」终端卡（逐字输入“帮我做一段开场动画”），连线接入画面，盖章确认后定格。

“vibe coding” 是 Andrej Karpathy 2025 年提出的说法，没有官方 logo，因此用终端卡 + 等宽字 + 波浪线作为它的视觉符号。
